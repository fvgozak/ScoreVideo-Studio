# ScoreVideo Studio: 한/영 JSON 언어팩

현재 UI 언어는 한국어(`ko`)와 영어(`en`)입니다. 번역 원문과 영어 번역은 각각
`static/locales/ko.json`, `static/locales/en.json`에 저장합니다.

## 신규 기능 작성 규칙

- **언어 문구를 `static/i18n.js`에 추가하지 마세요.** 이 파일은 로더 및 DOM 갱신 엔진입니다.
- 신규 레이블, 버튼, 툴팁, 오류, 완료 메시지는 양쪽 JSON의 `messages`에 같은 키로 등록합니다.
- JS: `window.ScoreI18n.t('score.cropTop')` 또는 `window.ScoreI18n.t('export.progress', {percent: 50})`를 사용합니다.
- 단순한 텍스트 DOM: `<span data-i18n="score.cropTop">악보 상단 자르기</span>`처럼 지정합니다.
- 속성: `data-i18n-title="some.key"`, `data-i18n-placeholder="some.key"` 등을 지정합니다.
- `data-i18n`은 자식 태그가 없는 **단일 텍스트 요소**에 적용합니다. `<button>` 내부에 아이콘이 있으면 아이콘을 유지하고 텍스트 부분의 `<span>`에 적용합니다.
- HTML 삽입 대신 가능하면 `textContent = ScoreI18n.t(...)`를 사용하세요.
- 숫자·날짜·진행률 등 변수는 `{percent}` 형태로 선언하고 양쪽 언어에 같은 플레이스홀더를 사용합니다.
- 프리셋, 설정 값, API 값, enum 값은 번역하지 않습니다. 표시 이름만 번역합니다.
- 사용자가 입력한 제목, 파일명, MusicXML 악보 내용은 번역하지 않습니다.
- 언어 변경은 `#languageSelect`, `ScoreI18n.setLocale('en')`로 적용되며 `localStorage('scorevideo_language')`에 저장됩니다.
- 초기 언어팩 로딩을 기다려야 할 때 `await ScoreI18n.ready`를 사용합니다.

## 기존 코드와의 호환

기존에는 `static/i18n.js`에 `english` 사전 404개와 정규식 41개가 직접 선언되어 있었습니다.
현재는 이를 JSON의 `legacy`와 `patterns`로 이전하고, 빠졌던 화면·상태 문구를 보강했습니다.
기존 JavaScript에서 한국어로 생성한 텍스트도 MutationObserver가 번역합니다. *앞으로 새 기능은
`legacy` 방식을 늘리는 대신 `messages`의 안정적인 키를 사용하세요.*

현재 방식은 **소스 변경 위험을 줄이기 위한 호환 계층**입니다. 기존 UI 전체를 일괄 교체하지 않았으며
신규 코드부터 `t()` 또는 `data-i18n`으로 옮기는 것이 최종 방향입니다.

## 검사 및 테스트

```sh
python scripts/check_i18n.py
python -m pytest -q tests/test_i18n_packs.py
```

검사기는 한국어·영어 키 일치, 플레이스홀더, 동적 번역 패턴, HTML 내 한국어 문구 누락을 검사합니다.
JS 전체의 임의 문구를 완벽히 식별하는 정적 분석기는 아니므로, **신규 UI 개발에서는 언어 전환을
실제 브라우저에서도 확인**해야 합니다.

### 주의할 점

- 사용자 정의 텍스트, OSMD 악보 SVG 영역, `#projectTitle`은 자동 번역하지 않습니다.
- 언어팩 JSON은 FastAPI 정적 경로(`/static/locales/`)에서 로드됩니다. `file://`로 HTML을 바로
  열면 브라우저 보안 정책 때문에 `fetch`가 제한될 수 있으므로 기존 `run.command`로 실행합니다.
- `i18n.js`는 언어팩 요청이 실패하면 콘솔에 오류를 기록하고 원문을 유지합니다.
- 현재 JSON의 `legacy`는 한국어 원문을 키로 쓰는 이전 방식이며, 중복하거나 변경될 수 있으므로
  신규 기능에서는 영속적인 설정 식별자로 쓰지 않습니다.
