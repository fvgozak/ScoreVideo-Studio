# 초기 패치 v1–v15 작업 기록

이 문서는 사용자가 제공한 `ScoreMotion_PATCH_HISTORY_v1-v15.md`(작성 기준 2026-11-18)를 **과거 작업 자료**로 요약한 것입니다. 표의 패치 번호는 이 저장소의 Git 태그나 릴리스 번호가 아닙니다. 개별 패치의 적용·배포 여부를 이 문서만으로 단정하지 마세요. `main`에 확인된 변경은 [변경 기록](../CHANGELOG.md)에 따로 정리했습니다.

## 당시 측정의 해석

- v9 기록의 `svgCacheHits=8008`, `visibleSvgTiles=8066`은 해당 출력 구간에서 **약 99.28% 캐시 적중**을 뜻합니다. 모든 곡의 평균 성능을 뜻하지 않습니다.
- v11의 캐시 변경은 실제 `drawScore` 구간에서 `drawRevision`이 계속 증가해 기대한 효과를 내지 못했습니다. v12의 GPU 마스크가 후속 접근입니다.
- v12 기록의 `score` 약 125.96ms → 0.75ms, `compose` 약 138.32ms → 1.21ms는 **사용자가 측정한 특정 단계**의 평균입니다. 전곡 출력 시간의 가속비로 해석하지 않습니다.
- 720p 건반 누락 진단에서는 WebGL 원본과 최종 출력의 픽셀이 달랐습니다. v13은 그 전달 경로를 우회했으며, 당시 문서는 모든 해상도의 출력이 검증됐다고 주장하지 않았습니다.
